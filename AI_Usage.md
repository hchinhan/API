# AI Usage Declaration

During the development of this project, AI tools were used as a learning and coding assistant for the following tasks:

1. **Model & API Implementation and Explanation**
   - Assisted in writing and explaining the source code related to loading and running inference with the Hugging Face translation model (`Helsinki-NLP/opus-mt-ja-en`).
   - Guided the implementation of FastAPI endpoints (`GET /`, `GET /health`, `POST /predict`), Pydantic request validation, and error handling in `main.py`.

2. **Environment Setup Guidance**
   - Suggested terminal commands for creating and activating the Python virtual environment (`venv`) as well as identifying and installing the required library dependencies (`requirements.txt`).

3. **Documentation Formatting**
   - Helped organize, refine, and format the `README.md` file to ensure a clean, consistent, and easy-to-follow layout.

4. **Test Script Implementation**
   - Assisted in converting the user-defined test cases (including valid Japanese anime dialogues and various invalid/edge-case inputs) into executable Python code using the `requests` library in `test_api.py`.
